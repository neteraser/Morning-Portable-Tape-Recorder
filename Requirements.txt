Requirements.

Morning Portable Tape Recorder requires DirectX SDK and DirectX Runtime Redist packages to be installed.

This package is easy to compile for Windows with the free compiler from Microsoft, Microsoft Visual Studio 18 2026 Community, which is what I currenly use with gratitude to Microsoft.

Also you need a stable version of the BASS Library and the LAME encoder (both supplied in the package).

The EQ Plugin is using the latest version of the Intel MKL (Math Kernel Library) and it's Intel MPI addon, which can be downloaded from Intel's official website, alternatively you can use simpler KissFFT library, which is also included in the source code.
